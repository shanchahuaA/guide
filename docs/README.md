## 一分钟版本

如果你现在只想知道"我该干什么"，看这五条：

1. **克隆**代码 —— 在 IDEA 里用 `Clone Repository`，**不要**点网页上的 Download ZIP
2. **从 `dev` 建你自己的分支** —— 名字用拼音，比如 `laowang`
3. **每天开工前先拉取** —— `Ctrl+T`
4. **写完就提交、推送** —— `Alt+0` 提交，`Ctrl+Shift+K` 推送
5. **要给别人用，就合并进 `dev`** —— 先切到 `dev`，再合并自己的分支

## 三条绝对不能做的事

- ❌ 点 `Force push`
- ❌ 直接往 `main` 上推
- ❌ 改别人的文件

## 卡住了怎么办

在群里一次给齐三样东西：**你在哪条分支 + IDEA 底部输出原文 + GitHub 上的实际状态**。
只说"我推不上去了"没人帮得了你。

详细做法见[新队友入职指南](onboarding.md)最后一节。
